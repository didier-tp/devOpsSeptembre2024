installation de la partie cliente seulement de mariadb ou MySQL de manière à tester une image docker construite en fin de journée:
-----------------------------------
sudo apt-get install mariadb-client
mariadb --version

Voir cette documentation pour savoir comment lancer automatiquement un script SQL avec une image docker mariadb:
-----------------------------------------------------------------------
https://mkyong.com/docker/how-to-run-an-init-script-for-docker-mariadb/
